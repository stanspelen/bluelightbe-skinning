# BlueLightBe Skinning

Portfolio voor **Farming Simulator** machine skins en **FiveM** hulpdiensten-skins (BelgiëPD + overig).

## Snel starten

Open `index.html` in de browser, of:

```bash
python -m http.server 8000
```

## Aanpassen

Zie **[BEWERKEN.md](BEWERKEN.md)** – foto’s, teksten, nieuwe kaarten, contactformulier.

## Structuur

```
├── index.html          Home
├── over-mij.html
├── projecten.html

        ├── belgiepd/
        └── fivem/
```
